This is a rewrite of my personal NixOS configuration, implementing the dendritic formatting and cleaning up a lot of the spaghetti code in the process. Eventually, this will extend to other devices I'm looking to bring under the Nix umbrella.

** Goals
To get a specific list to attempt consistency, I am going to spit out some rules on how this is going to play out.

- Modules should only contain relevant derivations, leaving as much room for importing and merging attribute sets as possible.
  - Window rules being defined alongside apps when applicable, for example.
- Aim for efficiency in compilation, as well as maintainability. 

 

** File Structure

*** =/modules=
Contains any /nix code/ to be used within the repo itself. This includes anything wrapped (shell scripts and the like).

**** =/base=
Contains basic settings for all devices. Think timezone and all that stuff.

**** =/hosts=
Any device being managed under this repo has it's own segment of configuration, which takes in the modules it needs using flake-parts. Most settings are not defined here, simply brought together for one use. 

***** nix-solid
Main desktop machine. May use disko in the future for management, but as of now it's not necessary. 

***** nix-liquid
Laptop config. Utilizing disko and preservation for an impermanence setup, as it's light on storage and nothing on it is expected to last long term.

***** nix-solidus
Currently not in use, but when a test / temporary desktop machine is needed this will be used.

***** nix-heaven
NAS machine. Most, if not all, self-hosted services.

** Custom options
These can be messy after a while, so I want to write some of it down.

*** device-type
Defines a device's "type", as in broad category of what it's used for. One of four options, which enables or disables specific features by default.

#+begin_src nix
  options.device-type = lib.mkOption {
    description = ''
        Defaults for device type. One of:

        "primary"
        "secondary"
        "server"
        "virtual"
      '';
    type = lib.types.enum [
      "primary"
      "secondary"
      "server"
      "virtual"
    ]; 

    default = "secondary";
  };
#+end_src

*** headless-check
This is a bool that defines, in a shorthand manner, if a device is intended to be interacted with directly on a frequent basis. This is mainly to restrict desktop environments and other unecessary packages from building on servers or virtual machines.

When /true/, a device is intended to have a desktop environment and whatnot. When /false/, it is not. This is mostly to help in the logic elsewhere.

#+begin_src nix
  options.headless-check = lib.mkOption {
    type = lib.types.bool; 
    description = "Is this device intended to have a desktop environment? True for a desktop, false for headless (to simplify logic elsewhere).";
    default = if config.device-type != isheadless then true else false;
  };
#+end_src

*** high-performance
For when battery or performance isn't as much of a concern. If it's a primary device, it defaults to true.

#+begin_src nix
  options.high-performance = lib.mkOption {
    type = lib.types.bool;
    description = "Does this computer have good resources?";
    default = if config.device-type == "primary" then true else false;
  };
#+end_src

** Shared options

*** Firefox
Firefox profiles are declared with the user's profile itself. They get re-used with any of it's derivitives that can be declared in the same way (LibreWolf, Floorp, etc). By default, LibreWolf is enabled instead of Firefox. 

There may be better ways to declare which one is enabled for the user, such as stating the package that Firefox builds on, but for the moment it's just conditional.
